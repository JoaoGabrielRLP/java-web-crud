Projeto de portfólio

Gerencie produtos de forma simples

Uma aplicação web completa para cadastrar, listar, buscar, editar e excluir produtos com persistência em PostgreSQL.

Cadastrar produto Ver produtos
Tecnologias Java 17 JSP PostgreSQL Tomcat

Como funciona

1. Cadastrar

Informe código, nome, marca e preço.

2. Consultar

Veja a lista completa ou filtre pelo nome.

3. Gerenciar

Atualize ou exclua um registro com confirmação.

Área de demonstração

Use apenas dados fictícios. A tabela pode ser preparada com os produtos de demonstração descritos no README.
